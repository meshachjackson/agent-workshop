# Security policy

## Report a problem privately

Do not open a public issue for a security problem.

1. Go to the **Security** tab of this repository.
2. Choose **Report a vulnerability**. This opens a private advisory that only
   the maintainers can see.
3. Say what you found, how to reproduce it, and what it could let someone do.

You can expect a first reply within 7 days. We will tell you when a fix is out
and credit you in the advisory if you want that.

## What to include

- The version or commit you tested.
- Steps to reproduce, or a small proof of concept.
- Your view of the impact.

## Supported versions

Only the latest release and the `main` branch get security fixes.

## If you find a secret

If you spot a real key, token or password in this repository or its history,
report it the same way. Do not use it.
